Can a few numbers flag a health risk early?

A risk-prediction dashboard for Type 2 diabetes, heart disease, hypertension and stroke that combines engineered features with clinical guidelines.

What I built

A dashboard that estimates a person’s risk for four conditions: Type 2 diabetes, heart disease, hypertension and stroke. The models use engineered features alongside clinical guidelines, so a prediction can be read next to the rule a clinician would recognise.
